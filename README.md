## 開発環境の使い方

### Codespaceを起動する

GitHub Classroomの課題リンクからリポジトリを作成したら、リポジトリのページで **Code** → **Codespaces** → **Create codespace on main** をクリックします。

初回起動時はコンテナのビルドに数分かかります。

### Javaプログラムの実行

VS Codeのエディタで `.java` ファイルを開くと、右上に再生ボタン（▷）が表示されます。クリックするとプログラムが実行されます。

### jshellの使い方

jshell（Java対話型実行環境）を使って、コードの動作を手軽に試すことができます。

1. VS Codeの画面上部のメニューから **ターミナル** → **新しいターミナル** を選択（またはショートカット `` Ctrl+` ``）
2. ターミナルで以下を入力して起動:
   ```
   jshell
   ```
3. Javaの式や文を直接入力して実行できます:
   ```
   jshell> System.out.println("Hello")
   Hello

   jshell> int x = 10
   x ==> 10

   jshell> x * 2
   $3 ==> 20
   ```
4. 終了するには `/exit` と入力します。

### GUIアプリケーションの表示

JavaのGUIアプリケーション（Swing等）を実行すると、ポート6080が自動で検出されます。

1. VS Codeの「ポート」タブを開く
2. ポート **6080**（noVNC web client）の地球アイコンをクリック、またはURLを開く
3. ブラウザ上のnoVNC画面にGUIが表示される

パスワードを求められた場合は `vscode` と入力してください。

### 使用上の注意

- **使い終わったらCodespaceを停止してください。** Codespaceは起動中ずっと無料枠を消費します。リポジトリページの **Code** → **Codespaces** から、該当のCodespaceの「...」メニュー → **Stop codespace** で停止できます。
- 無料アカウントでも月120コア時間（2コアマシンで約60時間）の無料枠があり、通常の授業利用には十分ですが、停止し忘れると枠を使い切る可能性があります。
- **GitHub Education** に学生登録すると無料枠が大幅に増えます。登録しておくと安心です: https://education.github.com/students
